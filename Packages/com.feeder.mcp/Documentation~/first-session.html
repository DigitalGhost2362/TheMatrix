Get started

Your first session

Check that the link works, give your client a first task, and learn the few habits that keep a shared Editor calm.

Check the link#

Keep Unity open with your project, start your client in the project folder and ask:

Check that the Unity editor is linked, then list the open scenes and how many objects each has.

The client calls editor-health and rql-query and answers with your scenes. In Unity, the Bridge window flashes WORKING and shows the tool being called.

If the client says it has no Unity tools, or the editor is not linked, see Troubleshooting.

Good first tasks#

AskWhat happens in Unity
"Find every object with a missing script in the open scene."One read-only query. Nothing changes.
"Show me the Game view and describe what the player sees."A screenshot of the Game view goes back to the client.
"What errors are in the console? Explain the first one and fix it."Reads the Console, edits the script, refreshes, reads the Console again.
"Rename all objects under Props to Prop_01, Prop_02 and so on. Dry run first."Lists the changes, then applies them as one undo step.
"Enter play mode, wait five seconds, take a screenshot, exit play mode."Play mode runs while you watch, then stops.

How the client finds more tools#

Only the core tools are on at first. When a task needs another one, the client looks it up with unity-tool-list and switches it on with tool-set-enabled-state. Claude Code sees a newly switched-on tool at once; other clients may need a reconnect, and until then they can call it through tool-call.

You can also switch tools on yourself in the Skills window, for example rql-mutate when you want the client to change many objects at once.

Habits that help#

  • Save before a big change. Scene edits are recorded as undo steps (Ctrl + Z works), but they are not saved for you. Save when you like the result.
  • Ask for a dry run. Queries that change things can list every change first and revert it. Say "dry run first".
  • Press Ctrl + R after your own file edits. Setup turned Auto Refresh off; the client refreshes for its own edits.
  • Let it finish before you click play. While a client holds the Editor, every Scene view has a green frame. See Several agents, one Editor.
  • Switch on only what you use. Every tool that is on costs tokens in every request. The Skills window shows the total.
Skills come with the toolsMatrix writes a short guide per tool into .claude/skills/matrix-*, plus a few guides of its own: matrix-shared-editor (how to share the Editor), matrix-setup-checklist and an optional /matrix persona that makes the client speak as the System of the simulated world.
