Troubleshooting

Find your symptom, try the fix. Most problems come down to an old client session, a dialog open in Unity, or a file edited outside Unity.

The Matrix Bridge menu items are greyed out#

Matrix is not turned on for this project on this machine. Run Tools > Feeder > Matrix Bridge > Getting StartedToolsFeederMatrix BridgeGetting Started. If you turned it off from the Bridge window, click OFFLINE there instead.

My client has no Unity tools#

  • Start a new session. A client session opened before Setup, or before the config was written, does not see the server.
  • Start it in the right folder. Claude Code reads .mcp.json from the folder you start it in: the one that holds Assets.
  • Approve the server. In Claude Code, /mcp shows Feeder-MCP. If it is disabled or waiting for approval, approve it.
  • Check the config exists. For other clients, open the Bridge window and make sure the client's name has a mark under it. Click it if not, then restart the client.

The client says the editor is not linked#

  1. Look at the Bridge windowIt should read ONLINE. LINKING for more than a minute, or FAULT, points at the server: click the word to retry.
  2. Ask for editor-healtheditor-health names what holds Unity: a modal dialog, a compile, a script reload. Close the dialog or wait for the reload.
  3. Reinstall the serverFrom the Bridge window's ... menu, choose Reinstall server. Do this after a package update that left the server failing to start.
  4. Read the logsTools > Feeder > Matrix Bridge > Server > Open LogsToolsFeederMatrix BridgeServerOpen Logs.

Calls time out while Unity compiles or imports#

Normal for long imports: calls wait up to reconnectGraceMs (180 s) for a reload. For longer work, raise the deadlines in UserSettings/Feeder-MCP-Config.json (see Deadlines), or ask the client to run long C# with timeoutSeconds.

My script changes do not show up#

Setup turned Auto Refresh off. Press Ctrl + R in Unity after you edit files outside Unity. Changes your client makes are refreshed through assets-refresh.

If a script changes while you play, Unity now compiles it after you stop playing.

A new tool is "not found"#

The tool is off, or the client has not reloaded its tool list. Switch it on in the Skills window. Claude Code sees it at once; other clients need a reconnect, or can call it through tool-call meanwhile.

A tool waits, or says the editor is held#

Another session holds the editor lock. The Bridge window names the holder and its task. Wait, or free a stuck claim from the lock line menu. See Several agents, one Editor.

Play mode stops when I switch to my terminal#

Run In Background is off. Setup turns it on; if you reverted Setup, turn it on in Player Settings.

The port is taken#

Another program uses this project's port. In the Bridge window, click the state word to go offline, then choose Change port from the ... menu. Clients with an amber mark have the old port: click them to rewrite their config.

The Bridge window lags#

Turn the rain background off: ... menu, Rain.

Teammates see .mcp.json changes in their diff#

The file was committed before Setup ignored it. See Team projects for the command to run.

Still stuck#

Collect three things and send them with your report: the result of editor-health, the server log from Tools > Feeder > Matrix Bridge > Server > Open LogsToolsFeederMatrix BridgeServerOpen Logs, and the version in Package Manager.
