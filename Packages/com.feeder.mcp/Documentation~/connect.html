Get started

Connect your AI client

Your client needs one thing: the address of the Matrix server. Matrix writes it into the client's config file for you, either automatically (Claude Code) or with one click in the Bridge window.

Claude Code: already done#

After Setup, Matrix writes .mcp.json in the project root on every Editor load, with this machine's port:

{
  "mcpServers": {
    "Feeder-MCP": {
      "type": "http",
      "url": "http://localhost:25213/mcp"
    }
  }
}
  1. Start Claude Code in the project folderOpen a terminal in the folder that holds Assets and Packages, and run claude. A session that was already open does not see the new server: start a new one.
  2. Approve the serverThe first time, Claude Code asks whether to use the Feeder-MCP server from .mcp.json. Approve it.
  3. Check the linkType /mcp. Feeder-MCP should read connected. Then go to Your first session.
Your port is your ownThe port comes from the project's folder path, so it differs between machines and between two copies of the same project. Never copy .mcp.json from a teammate; Matrix rewrites it on each Editor load.

Any other client: one click#

  1. Open the Bridge windowChoose Tools > Feeder > Matrix Bridge > BridgeToolsFeederMatrix BridgeBridge.
  2. Click your client's nameThe row at the bottom lists clients. Click a name to write its config; click +N to see the rest. A dot under the name means it is wired. An amber dot means the config is out of date: click to rewrite it.
  3. Restart the clientMost clients read their MCP config only when they start or when you open the project again.

Click a wired name again to remove its entry. Matrix only ever edits its own Feeder-MCP entry and leaves the rest of the file alone.

A client that is not listed#

Any client that speaks MCP over Streamable HTTP works. In the Bridge window, open the ... menu and copy the endpoint, then add it to your client by hand under the name Feeder-MCP. For a listed client whose file you manage yourself, right-click its name and choose Copy config JSON.

http://localhost:<port>/mcp

The port is in UserSettings/Feeder-MCP-Config.json (host) and in the Bridge window under the state word. The server listens on 127.0.0.1 only: other machines cannot reach it.

Turn auto-configure off#

Matrix rewrites .mcp.json on each load so the port is always right. If you manage that file yourself, set "claude-code": false under agentAutoConfigure in UserSettings/Feeder-MCP-Config.json. The same switch exists for the other clients you wired.
