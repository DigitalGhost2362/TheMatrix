Get started

Install and update

Matrix Bridge is a normal Unity package installed from a git URL. Installing it changes nothing until you turn it on, so it is safe to add to a shared project.

Before you start#

  • Unity 2022.3 or newer.
  • Git installed and on the PATH, because Unity downloads the package with git. Check with git --version in a terminal.
  • Windows x64, macOS (Intel or Apple silicon) or Linux x64. The package carries a ready-made server for each. You do not install .NET or anything else.
  • An MCP client, for example Claude Code, Codex or Cursor. See Connect your AI client for the full list.

Install#

  1. Open Package ManagerIn Unity, open Window > Package ManagerWindowPackage Manager.
  2. Add from git URLClick + in the top left corner, choose Add package from git URL, paste this URL and click Add: 
    https://github.com/DigitalGhost2362/TheMatrix.git?path=/Packages/com.feeder.mcp
  3. Wait for the importUnity downloads and compiles the package. A new menu appears: Tools > Feeder > Matrix BridgeToolsFeederMatrix Bridge. Most of its items stay greyed out until you run Setup.

Prefer editing files? Add the same URL to Packages/manifest.json and Unity installs it on the next focus:

{
  "dependencies": {
    "com.feeder.mcp": "https://github.com/DigitalGhost2362/TheMatrix.git?path=/Packages/com.feeder.mcp"
  }
}
Nothing runs yetInstalling does not start a server, open a window or write a file. Teammates who never run Setup are not affected, even when the package is committed with the project. Next step: turn Matrix on.

Update#

Open Window > Package ManagerWindowPackage Manager, select Matrix Bridge and click Update. Unity fetches the newest version from the main branch. The Editor installs the matching server on its next load.

Matrix checks once a day for a newer version and shows a popup when there is one. Turn that off under Tools > Feeder > Matrix Bridge > Update CheckToolsFeederMatrix BridgeUpdate Check.

After an update, start a new session in your AI client so it picks up the new tool list. Read What's new to see what changed.

Coming from version 0.87 or earlierThe first load stops the old Matrix server, removes the files it left in Library and rewrites every wired client config. Restart your AI client session afterwards.

Projects that used the Matrix registry#

In Packages/manifest.json, replace the com.feeder.mcp version number with the git URL above, and remove the Matrix entry under scopedRegistries.

Remove#

  1. Undo SetupClick Revert in Tools > Feeder > Matrix Bridge > Getting StartedToolsFeederMatrix BridgeGetting Started. It stops the server, puts back the Editor settings Setup changed and removes the lines Setup added to .gitignore. See Undo Setup.
  2. Remove the packageIn Package Manager, select Matrix Bridge and click Remove.
  3. Clean up what staysDelete the Feeder-MCP entry from .mcp.json (and from other clients you wired), the matrix-* folders under .claude/skills, and Library/feeder-matrix.
