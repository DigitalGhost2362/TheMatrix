Get started

Turn Matrix on

Run Setup once on each machine. It starts the local server, links the Editor, and changes a few Editor settings so an AI client can work in Unity without fighting you for it.

Run Setup#

  1. Open SetupChoose Tools > Feeder > Matrix Bridge > Setup...ToolsFeederMatrix BridgeSetup....
  2. Read the list and click RunThe dialog lists every change before it makes any. The same list is below.
  3. Read the resultA Setup finished window reports each step. The other Matrix Bridge menu items are now enabled, and the Bridge window reads ONLINE.

The on/off choice is stored for this machine and this project folder, outside the project. It is never committed, so each teammate decides for themselves.

The core tools#

Setup leaves these switched on. Together they cost about 4.5k tokens per request.

ToolWhat your client uses it for
rql-query, rql-schemaRead anything in the open scenes, assets and console with one query.
console-get-logsRead the Console.
editor-application-get-stateCheck play mode, pause and compile state.
screenshot-game-viewSee the Game view.
assets-refreshImport changed files and compile scripts.
unity-tool-list, tool-set-enabled-stateFind another tool and switch it on when the task needs it.

Switch more on yourself in the Skills window, or browse them in the tool catalog.

Optional: faster play mode and Defender#

Two more steps depend on your project or need admin rights, so Setup leaves them out: entering play mode without a domain reload, and a Windows Defender exclusion for the project folder. Both make play tests faster. Ask your AI client to run the matrix-setup-checklist skill; it checks your project first and explains each change.

Undo Setup#

Run Tools > Feeder > Matrix Bridge > Revert Setups...ToolsFeederMatrix BridgeRevert Setups.... After a confirm dialog it:

  • puts back the values Auto Refresh, Script Changes While Playing and Run In Background had before your first Setup;
  • removes the lines Setup added to .gitignore;
  • restores which tools were switched on;
  • turns Matrix off: stops the server, unlinks the Editor and turns Hyper Testing off;
  • closes every Matrix window.

Client configs such as .mcp.json and the generated skill files stay. Nothing starts on the next load until you run Setup again.

Turn Matrix off for a while#

To pause Matrix without undoing your settings, open the Bridge window and click the state word while it reads ONLINE. The server stops, the menu items grey out, and nothing starts on the next load. Click it again while it reads OFFLINE to turn Matrix back on.
