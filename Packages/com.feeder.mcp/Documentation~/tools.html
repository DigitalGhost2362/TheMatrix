Tool catalog

All 58 tools, grouped as in the Skills window. 11 are on after Setup; switch on the others when a task needs them. Click a tool to read its full description.

Your client picks tools for you, so you rarely need this page to work. Use it to decide what to switch on, and to understand a tool name you see in your client. Tags: core on after Setup, read-only changes nothing, writes changes the project or Editor, destructive can delete or overwrite, server answered by the Matrix server and always on. Token counts are what a tool adds to every request while it is on.

RQQuery

Read and change many objects with one query.

Read anything in the open scenes, prefabs, assets, console and project with one pipeline query (objects | where Light.intensity > 1 | select name, $path). Filters, projects, sorts, groups and counts many objects in one call and answers as a compact text table. Use rql-schema for the syntax and a type's members, rql-mutate to change things.

Syntax card of the query language plus the component types present in the open scenes; with typeName, the members (type, read or write) and methods of that type. Call it before writing a rql-query or rql-mutate query you are unsure of.

Works with rql-query, rql-mutate

Change many objects, components and assets in one query: objects | where name startswith "Enemy" | set Rigidbody.mass = 2. Also call methods, add components, destroy objects and create them with new(...). All-or-nothing, one undo step, optional dry run.

Search Unity's package registry plus locally installed packages by query string, or list the installed packages (installedOnly=true). Returns available versions and installation status. Online mode fetches exact matches from the live registry then supplements with cached substring matches.
