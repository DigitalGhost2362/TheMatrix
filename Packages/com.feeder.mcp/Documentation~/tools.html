Tool catalog

All 121 tools, grouped as in the Skills window. 8 are on after Setup; switch on the others when a task needs them. Click a tool to read its full description.

Your client picks tools for you, so you rarely need this page to work. Use it to decide what to switch on, and to understand a tool name you see in your client. Tags: core on after Setup, read-only changes nothing, writes changes the project or Editor, destructive can delete or overwrite, server answered by the Matrix server and always on. Token counts are what a tool adds to every request while it is on.

Runs up to 100 different Unity tools in order in one call, for example create an object, add a component, assign a material. All commands are validated first (unknown, disabled or forbidden tools run nothing). stopOnError (default true) stops at the first failing command. atomic=true makes the batch one undo step ('Matrix batch') and, if any command fails, reverts it with the undo stack (implies stopOnError); only undo-recorded changes revert, not disk writes or saved assets. Not allowed inside a batch: batch-execute, tool-call, editor-health and the editor-lock tools. Tools that finish later (compile, assets-refresh, test runs) count as an error and stop the batch: run them alone. Limits: the batch counts as an editor-changing call for the editor lock even when every command only reads, and the commands skip your client's per-tool permission rules, only batch-execute itself is checked.
