Two tools the server answers itself

These come from the server, not from Unity, so they are listed and work even while the Editor is hung, reloading or closed.

  • [[tool:editor-health]] says whether the Editor is responsive, busy, reloading, stalled or not linked, and what holds it: its open windows and dialogs, the Matrix calls in flight and the last lines of the Editor log. A tool that times out ends its error with the same summary.
  • [[tool:tool-call]] calls a Unity tool by name when it was just switched on and the client has not listed it yet. Clients that follow tools/list_changed rarely need it.

When your client says Unity is not answering, ask it to call [[tool:editor-health]]. A modal dialog in Unity (a save prompt, an import error) is the most common cause: close it.

Deadlines

Set in UserSettings/Feeder-MCP-Config.json and read when the server starts. Restart the server after a change: in the Bridge window, click the state word to go offline, then click it again.

KeyDefaultLimits
timeoutMs60 sone tool call
reconnectGraceMs180 show long a call waits for an Editor that is reloading scripts
deferredToolTimeoutMs15 mintools that finish after a compile or a domain reload, such as tests

[[tool:script-execute]] takes timeoutSeconds for code that runs long on purpose.

What tool-call refuses

[[tool:tool-call]] respects your Claude Code permissions. It refuses:

  • itself and [[tool:editor-health]];
  • a tool the calling session already lists: call it by its real name;
  • a tool covered by a Claude Code deny or ask rule, or by a PreToolUse hook that matches the tool but not tool-call itself, in the managed settings, .claude/settings.json, .claude/settings.local.json or your user settings.json;
  • every call while one of those files cannot be read or parsed; the error names the file.

It cannot see rules passed on the command line (--disallowedTools, --settings), rules added during a session, remote or MDM policy, or hooks from plugins, skills and agents. When those matter to you, turn it off: set enableToolCallProxy to false in UserSettings/Feeder-MCP-Config.json and restart the server.
