Start it

Unity -batchmode -nographics -projectPath <project> -executeMethod Feeder.MCP.Editor.MatrixBatch.Run
      [-matrixIdleSeconds 900] [-matrixMaxSeconds 0] [-matrixReadyTimeoutSeconds 180]
      [-matrixQuitFile <path>] [-matrixReadyFile <path>]
Leave out -quitWith -quit, Unity exits as soon as the method returns and the server goes with it.

The entry installs and starts the project's server (also when CI=true), links the Editor and writes a ready file. It does not need Setup and does not write client config files.

Connect your client

Wait for Temp/matrix-batch.ready.json (or the path you passed with -matrixReadyFile). It holds mcpUrl: give that URL to your client as an MCP server over HTTP.

When it stops

OptionDefaultStops the Editor when
-matrixIdleSeconds900no tool was called for this long (0 = never)
-matrixMaxSeconds0this much time has passed in total (0 = no limit)
-matrixQuitFileTemp/matrix-batch.quitthis file appears: create it to stop the run cleanly
-matrixReadyTimeoutSeconds180the server is not ready in time: exits with code 2
