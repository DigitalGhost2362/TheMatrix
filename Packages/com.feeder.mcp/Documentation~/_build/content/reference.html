Menu items

Everything sits under [[menu:Tools > Feeder > Matrix Bridge]]. Until you run Setup, only Setup is enabled.

ItemDoes
Setup...Turns Matrix on for this machine and project. See Turn Matrix on.
Revert Setups...Puts back what Setup changed and turns Matrix off.
SkillsSwitch tools on and off. See Choose tools.
BridgeLink state, clients and the editor lock. See Bridge window.
Hyper Testing (Experimental)Clone Editors for parallel play tests. See Hyper Testing.
VFX Studio (Experimental)Browse VFX prefabs, edit an effect with a live preview and generate particle textures.
Capture > Capture Focused WindowSaves the focused Editor window as a PNG in Docs/Captures/<title>.png.
Capture > Capture Window...Pick any open Editor window to save the same way.
Server > Reinstall BinariesExtracts the bundled server again.
Server > Delete BinariesRemoves the extracted server from Library/feeder-matrix.
Server > Open LogsOpens the server log folder.
Server > Launch MCP InspectorOpens a generic MCP inspector against the server, to see the raw tool list and try calls.
Server > Reset ConfigResets UserSettings/Feeder-MCP-Config.json to defaults and reloads scripts.
Server > Link Play Mode As PlayerLinks each Play session for runtime tools.
Update Check > Check NowLooks for a newer version tag of the package now.
Update Check > Enabled For Me / For This ProjectMatrix checks once a day for a new version and shows one popup per release. Untick For Me to stop it on your machine, or For This Project to stop it for everyone (it writes a file under ProjectSettings).

Settings file

UserSettings/Feeder-MCP-Config.json holds this machine's settings. Most are changed from the windows; these are the ones you may edit by hand. The server reads them when it starts.

KeyDefaultMeaning
hostderived from the folder pathServer address and port.
tokengeneratedSecret that players and the Editor use to link. Keep it private.
logLevelWarningServer log detail.
timeoutMs60000Deadline of one tool call.
reconnectGraceMs180000How long a call waits for an Editor that is reloading.
deferredToolTimeoutMs900000Deadline of tools that finish after a compile or reload.
enableToolCallProxytrueTurns [[tool:tool-call]] on or off.
agentAutoConfigureclaude-code onWhich client configs Matrix rewrites on each load.
skillsPath.claude/skillsWhere skill files are written.
toolscore set onWhich tools are on. Use the Skills window instead.

Environment

FEEDER_MATRIX_SERVER_PATH, read from the environment or from a .env file at the project root, runs a server build from that path instead of the bundled one. Use it only when you build the server yourself.
