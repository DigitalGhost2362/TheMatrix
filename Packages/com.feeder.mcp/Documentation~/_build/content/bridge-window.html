Open it with [[menu:Tools > Feeder > Matrix Bridge > Bridge]]. Dock it anywhere; a short wide strip is enough.

Reading it from top to bottom

PartWhat it tells you
State wordOFFLINE: not linked. LINKING: starting the server or reconnecting, for example after a script reload. ONLINE: ready. WORKING: a tool is running right now. PLAY TESTING: a session is playing the game. FAULT: the server failed to start; click the word to retry.
localhost:25213 - 2 agentsThe server address and how many client sessions are connected.
> script-executeThe tool that is running, shown while the state reads WORKING.
editor free or a lock cardWho holds the Editor. A card shows the client's name, its task and for how long it has held it. See Several agents, one Editor.
Client namesClick to wire or unwire a client. A mark under the name means it is wired; amber means its config is out of date. Right-click a name to copy its config JSON.

The window's tab icon dims while the Editor is not linked, so you can tell from a docked tab.

Turn the link on and off

Click the state word. While it reads ONLINE, a click turns Matrix off for this project on this machine: the server stops and nothing starts on the next load. Click OFFLINE to turn it back on. The same two clicks restart the server, for example after you edit its settings file.

The ... menu

The ... button in the top right corner opens these items:

ItemUse it to
Copy endpointPaste the server URL into a client that Matrix does not list.
Change portPick another port when the default one is taken. Only while offline. A client whose config still has the old port shows an amber mark: click it to rewrite the config.
LoggingSet how much the server writes to its log. Raise it only while chasing a problem.
SkillsOpen the Skills window.
RainTurn the falling-glyph background off on machines where it lags.
Open logsOpen the server log folder, Temp/feeder-matrix.
Open config fileShow UserSettings/Feeder-MCP-Config.json. See Settings file.
Reinstall serverExtract the bundled server again. Use it when the server fails to start after an update.

Scene view toolbar

Once Matrix is on, the Scene view gets a small Matrix Bridge overlay in its toolbar. Click it to open the Bridge window from where you are working.
